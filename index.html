💡 Why open — and why local

🔒 Private

Group chats are the most personal data most people have. SlothDigest runs a small open-weight model on your own machine — your messages never touch a server, so there is nothing to leak, sell, or subpoena.

💸 Free, forever

No API bill per message. Once the model is downloaded, every nightly digest costs exactly $0 — the kind of thing that only works when the model itself is open.

✈️ Offline

On a plane, on campus Wi-Fi that barely works, anywhere — the digest still runs, because nothing needs the cloud. Open weights turn "AI feature" into a utility you own.

This page is a simulation of the experience. The companion script agent.py in this repo runs the same digest for real: it reads an exported chat, summarizes it with a local model when one is available (Ollama-compatible endpoint), and falls back to a lightweight on-device extractive pass otherwise — no cloud, no API key, no data leaving the device.
